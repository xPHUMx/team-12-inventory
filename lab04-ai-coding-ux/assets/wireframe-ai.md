# Text Wireframe (ASCII Layout) - Lab 04

เอกสารนี้รวบรวม ASCII Layout Text Wireframe สำหรับ 3 หน้าจอหลักของระบบคลังสินค้า (Inventory Management System) ได้แก่ **Login**, **Dashboard**, และ **Add Product** โดยออกแบบตามความต้องการของ Persona "น้าศักดิ์" (ทักษะเทคโนโลยีระดับ 2.5) และรองรับสินค้า 2 ชนิด (สินค้ากายภาพ และสินค้าดิจิทัล) พร้อมระบุข้อกำหนด Usability และ Accessibility ครบถ้วน

---

## 1. หน้าเข้าสู่ระบบ (Login Page)

### ASCII Layout
```text
+--------------------------------------------------------------------------+
|  [Logo] ระบบจัดการคลังสินค้าและสต็อก (Team 12 Inventory)                  |
+--------------------------------------------------------------------------+
|                                                                          |
|                     +----------------------------------+                 |
|                     |            เข้าสู่ระบบ            |                 |
|                     +----------------------------------+                 |
|                                                                          |
|                     ชื่อผู้ใช้งาน (Username) *                           |
|                     +----------------------------------+                 |
|                     | somsak.m                         |                 |
|                     +----------------------------------+                 |
|                                                                          |
|                     รหัสผ่าน (Password) *                                |
|                     +----------------------------------+ [👁️ แสดงรหัส]   |
|                     | ••••••••••••                     |                 |
|                     +----------------------------------+                 |
|                     [!] รหัสผ่านไม่ถูกต้อง (กรุณาตรวจสอบปุ่ม Caps Lock)    |
|                                                                          |
|                     +----------------------------------+                 |
|                     |   [ ปุ่มหลัก: เข้าสู่ระบบ (Enter) ]   |                 |
|                     +----------------------------------+                 |
|                                                                          |
|                     ต้องการความช่วยเหลือ? ติดต่อผู้ดูแลระบบ: 02-123-4567   |
|                                                                          |
+--------------------------------------------------------------------------+
```

### คำอธิบายองค์ประกอบ (Usability & Accessibility)
1. **Visible Labels (`*`):** มีป้ายกำกับชื่อช่องชัดเจนอยู่ด้านบนช่องกรอก พร้อมเครื่องหมาย `*` สีแดงบอกว่าจำเป็นต้องกรอก ป้องกันความสับสนของผู้ใช้ระดับทักษะ 2.5
2. **ปุ่มแสดงรหัสผ่าน (`[👁️ แสดงรหัส]`):** ช่วยลดข้อผิดพลาดในการพิมพ์รหัสผ่านผิดสำหรับผู้ใช้ที่ไม่คล่องแป้นพิมพ์
3. **Actionable Error Message:** ข้อความแจ้งเตือนสีแดงไม่เพียงบอกว่าผิด แต่แนะนำวิธีแก้ไข เช่น *"กรุณาตรวจสอบปุ่ม Caps Lock"*
4. **Primary Button:** ปุ่มเข้าสู่ระบบมีขนาดใหญ่ คอนทราสต์สูง (#1E40AF) และรองรับการกด Enter ทันทีเมื่อกรอกเสร็จ

## 2. หน้ากระดานภาพรวม (Dashboard Page)

### ASCII Layout
```text
+--------------------------------------------------------------------------+
| [Logo] Team 12 Inventory | คลังสินค้า | รายงาน | [👤 น้าศักดิ์ (พนักงานคลัง)] [ออกจากระบบ] |
+--------------------------------------------------------------------------+
| หน้าหลัก > ภาพรวมสต็อกสินค้า (Dashboard)                                   |
|                                                                          |
| +---------------------+ +---------------------+ +----------------------+ |
| | สินค้าทั้งหมด         | | สินค้าสต็อกต่ำ (เตือน) | | มูลค่ารวมในคลัง       | |
| |    148 รายการ       | |   (!) 3 รายการ       | |    185,400.00 บาท    | |
| | [📦 กายภาพ: 120]    | | [ดูรายการเตือน ->]   | |                      | |
| | [💾 ดิจิทัล: 28]     | |                     | |                      | |
| +---------------------+ +---------------------+ +----------------------+ |
|                                                                          |
| ค้นหาสินค้า: [ พิมพ์รหัส หรือชื่อสินค้า...               ] [🔍 ค้นหา]     |
| ตัวกรอง: [ ทั้งหมด v ] [ กายภาพ v ] [ ดิจิทัล v ]   [ + เพิ่มสินค้าใหม่ (F2) ]|
|                                                                          |
| [ ตารางรายการสินค้า ]                                                      |
| +----------+-----------------------+----------+---------+--------+-------+|
| | รหัส     | ชื่อสินค้า             | ชนิด     | คงเหลือ | สถานะ  | จัดการ||
| +----------+-----------------------+----------+---------+--------+-------+|
| | WIRE-01  | สายไฟทองแดง 2.5 sq.mm | 📦 กายภาพ | 12 ม.   | ⚠️ ต่ำ | [แก้ไข]||
| | LIC-WIN  | Windows 11 Pro Key    | 💾 ดิจิทัล| 45 keys | ✅ ปกติ | [แก้ไข]||
| | BOOK-01  | คู่มือไฟฟ้าดิจิทัล (PDF)| 💾 ดิจิทัล| ไม่จำกัด| ✅ ปกติ | [แก้ไข]||
| | PIPE-02  | ท่อ PVC ขาว 1 นิ้ว     | 📦 กายภาพ | 4 เส้น  | ⚠️ ต่ำ | [แก้ไข]||
| +----------+-----------------------+----------+---------+--------+-------+|
| แสดงผล 1-4 จากทั้งหมด 148 รายการ                  [< ก่อนหน้า] [1] [2] [ถัดไป >] |
+--------------------------------------------------------------------------+
```

### คำอธิบายองค์ประกอบ (Usability & Accessibility)
1. **แยกประเภทสินค้าชัดเจน:** มี Badge สัญลักษณ์กำกับชัดเจนทั้ง `[📦 กายภาพ]` และ `[💾 ดิจิทัล]` พร้อมสรุปยอดใน Stat Card
2. **ปุ่มเด่นสำหรับเพิ่มสินค้า:** ปุ่ม `[ + เพิ่มสินค้าใหม่ ]` เป็น Primary Action วางตำแหน่งขวาบนของตาราง มองเห็นง่าย พร้อมคีย์ลัด (F2)
3. **การแสดงสถานะไม่พึ่งพาสีเพียงอย่างเดียว:** สถานะเตือนใช้ทั้งไอคอน `⚠️` และข้อความ `"ต่ำ"` ควบคู่กับสีเตือน (#B45309) เพื่อให้ผู้มีปัญหาตาบอดสีแยกแยะได้
4. **ตารางอ่านง่าย:** แถวของตารางมีเส้นแบ่งชัดเจน ความสูงพอเหมาะสำหรับการแตะสัมผัสหรือกวาดสายตา

| |     [ดูสินค้านี้ในคลัง]   [เพิ่มรายการต่อไป]                           | |

### คำอธิบายองค์ประกอบ (Usability & Accessibility)
1. **Segmented Radio Toggle:** มีสวิตช์เลือกชัดเจนระหว่างสินค้าจับต้องได้กับสินค้าดิจิทัล เมื่อคลิกจะเปลี่ยนเฉพาะส่วนข้อ 3 ช่วยแก้ Pain Point การกรอกสลับช่องของน้าศักดิ์ได้ 100%
2. **Inline Validation Error:** หากไม่กรอกช่องจำเป็น จะมีกรอบสีแดงและข้อความอธิบายใต้ช่องทันที เช่น *"[!] กรุณาระบุชื่อสินค้า (ห้ามเว้นว่าง)"*
3. **ป้องกัน Double-Click:** เมื่อกดปุ่มบันทึก ปุ่มจะเปลี่ยนสถานะเป็น Disable ทันทีและขึ้นข้อความ *"กำลังบันทึก..."* เพื่อป้องกันข้อมูลเบิ้ล
4. **Success Banner พร้อมทางเลือก:** เมื่อบันทึกเสร็จ จะมีแถบสีเขียว `#15803D` ขึ้นด้านบน พร้อมปุ่มให้เลือกว่าจะ "ดูสินค้านี้" หรือ "เพิ่มรายการต่อไป"
